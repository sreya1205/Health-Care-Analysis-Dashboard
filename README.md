# 🏥 Health Care Analysis Dashboard

## 📌 Overview
The **Health Care Analysis Dashboard** is an interactive Power BI dashboard designed to analyze healthcare billing, patient conditions, insurance providers, and demographic insights.  
It provides a comprehensive overview of healthcare-related metrics to help stakeholders make data-driven decisions.

---

# 📊 Dashboard Features

## 1. Key Performance Indicators (KPIs)
- **Average Bill Amount:** `25.54K`
- **Count of Doctors:** `40K`

These KPIs provide a quick snapshot of healthcare billing and doctor availability.

---

## 2. Filters / Slicers
The dashboard includes interactive filters for:
- **Gender**
  - Female
  - Male

- **Medical Condition**
  - Arthritis
  - Asthma
  - Cancer
  - Diabetes
  - Hypertension
  - Obesity

Users can dynamically filter the dashboard based on selected categories.

# 🚀 How to Use

1. Open the Power BI dashboard file.
2. Use the slicers on the left panel to filter data.
3. Hover over charts for detailed insights.
4. Analyze trends across billing, conditions, and insurance providers.
